Portfolio professionnel de Lolito Razafimaharo, développeur full-stack et DevOps.

- Next.js 16
- React 19

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

Présenter les compétences, services et projets d’un profil technique orienté résultat, avec un focus sur les applications web, SaaS, e-commerce et mise en production.
